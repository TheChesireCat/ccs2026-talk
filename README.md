# Inferring Mixing Patterns from Mobility Signals: Opportunities and Limitations

Slides for the CCS 2026 talk by Ankit Ramakrishnan, Irene Ferri, Allisandra G. Kummer, Marco Ajelli,
Alessandro Vespignani, Maria Litvinova and Matteo Chinazzi (Network Science Institute, Northeastern
University; Indiana University).

**View the slides:** https://thechesirecat.github.io/ccs2026-talk/

Built with [reveal.js](https://revealjs.com); everything it needs is bundled, so it also runs offline from a
local web server (`python3 -m http.server`, then open http://127.0.0.1:8000/). Arrow keys step through the
slides and their animations; Esc shows the overview.
